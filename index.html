The protocol · Identical for every tool

Same business. Same four calls. No favorites.

Each tool is configured with the same fictional plumbing company: same hours, same prices, same instructions. Then it takes the same four calls, recorded, including one designed to break it.

CALL 01

The easy one

Hours and service area. If a tool fumbles this, the test is over early.

CALL 02

The booking

A leaking water heater and a request for tomorrow morning. Does a real appointment show up?

CALL 03

The curveball

Interruptions, a changed mind, a price question out of nowhere. The rude-customer simulation.

CALL 04

The emergency

Water everywhere, right now. Does it recognize urgency or read a script?

About
